# Python-Projects
This repository is for python projects. 


UPDATE: A python chessboard with pieces and drag and drop has been pushed to this repository (Python-Projects).
Now you can add:
  Limitations to drag and drop
  Engine (Optional)
  FILE: chessboard.py

Or modify:
  The size (Using the BOARD_SIZE and SQUARE_SIZE variables)
  The hex values for the chessboard color.

Requires Tkinter, or python-chess for adding an engine. 'import chess' is what you need to type in for importing.
